# 2. ② Server-authoritative Combat

총을 쏘면

```text
Client
Input / 즉각적인 로컬 연출
 ↓
Server RPC
 ↓
Server hit validation
 ↓
Damage
 ↓
Replicated state
 ↓
Clients
```

식으로 동작하게 하세요.

여기서

- HP
- Ammo
- Fire
- Damage
- Death
- Respawn
- Revive

를 서버 권위로 처리합니다.

Unreal 공식 문서에서도 무엇을 어떤 클라이언트에 복제할 것인지, RPC와 replicated property를 어떻게 선택할지가 네트워크 게임의 핵심 문제라고 설명합니다. [Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/networking-overview-for-unreal-engine?lang=en-US\&utm_source=chatgpt.com)

면접관에게 보여주기 정말 좋은 영역입니다.

# 4. ④ Asset Management

이건 사용자님에게 특히 좋은 소재예요.

Addressables 사용 경험이 있기 때문입니다.

이번에는 Unreal에서

- Hard Reference
- Soft Reference
- TSoftObjectPtr
- Asset Manager
- Async Load

를 이용하세요.

Unreal도 hard reference를 잘못 사용하면 연관 에셋이 함께 로드될 수 있고, Asset Manager와 StreamableManager를 사용해 비동기 로딩을 제어할 수 있습니다. [Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/asset-management-in-unreal-engine?utm_source=chatgpt.com)

그러면 포트폴리오에서 아주 좋은 비교가 됩니다.

> Unity에서의 Addressables 경험을 바탕으로,  
> Unreal에서는 Soft Reference와 Asset Manager로 같은 종류의 문제를 어떻게 해결했다.

이런 설명은 **엔진을 외운 사람이 아니라 개념을 이해한 사람**처럼 보여요.

# 5. ⑤ Unreal Insights로 실제 성능 문제 하나 해결

이건 반드시 넣기를 권합니다.

일부러 문제를 만들어서 해결하면 안 되고, 개발하면서 실제 발견한 병목 하나를 잡으세요.

예를 들어:

```text
적 100마리 생성
↓
Game Thread 16ms → 28ms
↓
Unreal Insights 분석
↓
모든 AI Actor Tick 실행 확인
↓
Tick 제거 / 주기화 / event-driven 전환
↓
28ms → 17ms
```

같은 사례예요.

Unreal Insights는 CPU, memory, thread, network까지 프로파일링할 수 있습니다. [Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/introduction-to-performance-profiling-and-configuration-in-unreal-engine?utm_source=chatgpt.com)

사용자님의 프로파일링 경험을 **문제 → 프로파일링 → 원인 → 수정 → 실제 지표** 형태로 정리하세요.

그 패턴을 Unreal에서도 한 번 보여주면 굉장히 설득력 있어요.

> “Unity에서만 프로파일링할 줄 아는 사람이 아니네.”

라는 판단을 얻을 수 있습니다.

# 6. ⑥ C++다운 코드

여기도 중요합니다.

게임 기능을 C++로 작성했다는 것보다

- RAII
- UObject와 일반 C++ object lifetime 차이
- `TObjectPtr`
- `TWeakObjectPtr`
- `TSharedPtr`
- `TUniquePtr`
- delegate
- interface
- template
- const correctness

같은 C++/Unreal 수명 관리 개념을 이해하고 있다는 것이 더 중요합니다.

사용자님은 C/C++와 시스템 프로그래밍 학습 경험이 있으므로 완전히 새로운 축은 아닙니다.

이번 프로젝트는 **그 C++ 경험을 실제 게임 코드로 연결하는 프로젝트**가 되어야 해요.
