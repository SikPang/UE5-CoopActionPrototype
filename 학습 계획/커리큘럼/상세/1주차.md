# 4. Unity와 Unreal의 객체 모델을 비교하면서 시작하세요

이건 반드시 머리에 넣어야 해요.

Unity에서는 대략:

```text
GameObject
  └── Component
```

중심으로 생각했을 겁니다.

Unreal은:

```text
UObject
  │
  └── Actor
        │
        ├── Pawn
        │     └── Character
        │
        └── ActorComponent
              └── SceneComponent
```

식으로 봐야 해요.

Epic도 Unity의 GameObject와 가장 가까운 개념을 Actor로 설명하지만, Unreal에서는 Actor 자체에도 기능을 구현할 수 있다는 차이가 있습니다. [Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/game-objects-in-unreal-engine?utm_source=chatgpt.com)

### 오늘 반드시 이해할 차이

**UObject**

Unreal Reflection과 GC의 기반이 되는 객체예요.

**Actor**

World에 Spawn하거나 Level에 배치할 수 있는 UObject예요.

**ActorComponent**

Actor에 기능을 붙이는 객체예요.

**SceneComponent**

Transform을 가질 수 있는 Component예요.

**Pawn**

Controller에게 조종될 수 있는 Actor예요.

**Character**

CharacterMovement가 포함된 Pawn이에요.

지금은 외우는 게 아니라,

> 왜 Door는 Actor인데 InteractionComponent는 Actor가 아닌가?

를 생각하는 게 중요합니다.

# Day 6 — UObject Reference와 GC 실험

이번 주 가장 중요한 날 두 번째예요.

사용자님은 C++ 포인터와 수명 관리 학습 경험이 있습니다.

그렇기 때문에 Unreal에서 더 위험한 오해가 생길 수 있어요.

**UObject lifetime은 `new/delete` 중심으로 생각하면 안 됩니다.**

오늘은 다음 네 개만 비교합니다.

```text
UObject*
TObjectPtr<T>
TWeakObjectPtr<T>
TSoftObjectPtr<T>
```

공식 문서 기준으로 persistent UObject reference를 `UPROPERTY`로 보유할 때는 `TObjectPtr`가 일반적인 선택이고, weak/non-owning reference에는 `TWeakObjectPtr`, asset을 필요할 때 로드하려면 `TSoftObjectPtr`를 사용합니다. [Epic Games Developers](https://dev.epicgames.com/documentation/en-us/unreal-engine/object-pointers-in-unreal-engine?utm_source=chatgpt.com)

### 오늘 반드시 이해할 표

| 타입 | 의미 | 예시 |
|---|---|---|
| `TObjectPtr<T>` | UObject 강한 참조 | Character가 가진 Component |
| `TWeakObjectPtr<T>` | lifetime을 소유하지 않는 참조 | 현재 바라보는 Target cache |
| `TSoftObjectPtr<T>` | Asset path 기반 지연 참조 | 나중에 로드할 Mesh |
| Raw `T*` | 짧은 범위 접근 등에 사용 | 함수 내부 임시 접근 |

특히 중요한 것은:

```cpp
UPROPERTY()
TObjectPtr<UMyObject> MyObject;
```

처럼 **UPROPERTY와 함께 있을 때 GC가 이 참조를 추적**한다는 점이에요. [Epic Games Developers](https://dev.epicgames.com/documentation/en-us/unreal-engine/object-pointers-in-unreal-engine?utm_source=chatgpt.com)
