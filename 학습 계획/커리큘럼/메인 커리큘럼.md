**Unreal Editor가 낯설지 않고 C++로 게임 오브젝트를 자유롭게 생성할 수 있는 상태**


그리고 Unreal에서 굉장히 중요한


을 봅니다.

특히 Unity 출신이 처음 혼란스러워하는 게 **UObject lifetime**이에요.

`TObjectPtr`, `TWeakObjectPtr`, `TSoftObjectPtr`의 차이까지 이번 주에 한 번 봅니다. Epic은 현재 UObject를 지속적으로 보유하는 `UPROPERTY`에는 `TObjectPtr`, 필요할 때 로드하는 asset에는 `TSoftObjectPtr`, non-owning reference에는 `TWeakObjectPtr`를 권장합니다. [Epic Games Developers](https://dev.epicgames.com/documentation/en-us/unreal-engine/object-pointers-in-unreal-engine?utm_source=chatgpt.com)

# Week 8: Asset과 Loading

사용자님에게 아주 중요한 주입니다.

Addressables 사용 경험이 있습니다.

이걸 Unreal로 옮깁니다.

### 구현

처음에는 일부 asset을 hard reference로 연결해봅니다.

그리고 dependency와 memory를 확인합니다.

그다음

```text
TSoftObjectPtr
PrimaryDataAsset
AssetManager
Async Load
```

구조로 변경합니다.

Epic 문서에서도 hard UObject reference가 asset을 즉시 함께 로드할 수 있기 때문에, 필요하지 않은 asset의 강제 로딩을 피하기 위해 soft reference와 비동기 로딩을 사용하도록 설명합니다. [Epic Games Developers](https://dev.epicgames.com/documentation/unreal-engine/asynchronous-asset-loading-in-unreal-engine?utm_source=chatgpt.com)

### 최종 결과

포트폴리오에

```text
Hard Reference
↓
Dependency 증가
↓
Soft Reference
↓
Async Loading
```

Before / After를 넣을 수 있어야 합니다.
